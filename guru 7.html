Untuk menyimpan data agar bisa diakses orang tua, kita perlu menghubungkan ke Firebase (gratis dari Google). Lakukan sekali saja.
1
Buka console.firebase.google.com → klik Add project → beri nama (misal: kelas-mengaji)
2
Di menu kiri, klik Realtime Database → Create database → pilih lokasi Asia → pilih Start in test mode
3
Salin URL database-mu (berbentuk: https://nama-project-default-rtdb.asia-southeast1.firebasedatabase.app)
4
Tempelkan URL-nya di bawah dan klik Simpan
